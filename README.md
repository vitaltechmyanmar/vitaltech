# Vital Tech Myanmar

A static marketing website for Vital Tech Myanmar. The site presents software development, cloud, DevOps, system integration, and managed IT capabilities for organizations seeking a practical technology partner.

## Technology Stack

- [Astro](https://astro.build/) 7.2.8 for static site generation
- TypeScript 7.0.2 for typed site content and routes
- Tailwind CSS 4.3.3 with the Vite integration for styling
- `@astrojs/sitemap` 3.7.3 for generated sitemap files

## Prerequisites

- A current Node.js LTS release compatible with Astro 7.2.8
- npm

## Local Development

Install the locked dependencies from the workspace root:

```powershell
npm ci
```

Start the local Astro development server:

```powershell
npm run dev
```

Create a production static build:

```powershell
npm run build
```

Preview the generated static site locally after a successful build:

```powershell
npm run preview
```

## Project Structure

```text
src/
  components/       Shared Astro UI components
  content/          Centralized typed site content
  layouts/          Shared page layouts
  pages/            Static Astro routes
  styles/           Global styling
public/             Static assets, including technology icons
aidlc-docs/         Workflow and build/test documentation
dist/               Generated static build output
```

`dist/` is generated by `npm run build` and is ignored by Git. Do not edit its files manually; regenerate it after source or content changes.
