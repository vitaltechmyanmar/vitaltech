## Key Implementation Decisions
- Uses Astro static output with no backend, form submission, analytics, CMS, database, authentication, or runtime content service.
- Uses centralized typed content, metadata, navigation, and contact configuration.
- Uses the approved near-black, acid-lime, outlined-display, solid-focal-word, and dark-blue ambient visual direction as a Vital Tech Myanmar adaptation.
- Uses CSS gradients and styling primitives instead of video or large hero media.
- Uses a progressive-enhancement mobile navigation script; static route links and content remain in generated HTML.
- Keeps official phone, email, and WhatsApp endpoints as clearly labelled placeholders until supplied.
