# Theme Change Persona Addendum - Vital Tech Myanmar

## Reuse Decision
The existing personas remain valid because the theme refresh does not change the website’s audience, routes, content model, or direct-contact behavior. This addendum records the experience outcomes the new visual system must support.

## Strategic Technology Leader
- **Primary refresh need**: Identify the company proposition and priority services quickly in a credible, uncluttered editorial layout.
- **Key outcome**: Can compare Software Development, Cloud, and DevOps immediately after the Home hero, then progress to service detail or a direct-contact route.

## Technical Solution Evaluator
- **Primary refresh need**: Scan detailed service, industry, and insight content without visual noise or weak hierarchy.
- **Key outcome**: Can navigate dense capability information through clear grids, typography, and visible interactive states on desktop or mobile.

## Prospective Candidate
- **Primary refresh need**: Experience a credible, accessible, professional site while finding career context and a contact path.
- **Key outcome**: Can use the Careers route, responsive navigation, and placeholder contact presentation without ambiguity.

## Shared Accessibility Needs
All personas require semantic landmarks, visible keyboard focus, readable navy/blue/neutral contrast, responsive layouts, reduced-motion support, and stable access to the existing public routes.
